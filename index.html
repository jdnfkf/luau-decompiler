      说明 / 常见问题
      

        
这是什么：把 Roblox 游戏里的脚本字节码（getscriptbytecode 导出的那种）还原成可读的 Luau 源码。

        
隐私：整个过程在你的浏览器里跑，文件一个字节都不发出去，断网也能用。

        
怎么拿到字节码：在执行器里跑
          writefile("x.luau", getscriptbytecode(目标脚本))
          然后把 x.luau 传到手机，用这个页面打开。

        
还原度：控制流、字符串常量、表结构、API 调用名全部还原；变量名用启发式从用法反推
          （原游戏里的真名在客户端字节码里已被剥离，Roblox 官方也拿不回来）。

        
速度：650 KB 的大文件约 30~60 秒（取决于手机），期间界面不会卡。

        
引擎：unluac-rs（Rust）经 wasm-bindgen 编译成 WebAssembly，在本页内运行；
          Roblox v14 字节码与 opcode 混淆由本引擎自行解析。

      

    

  


  

    

      API 用法（可编程调用）
      

        
页面暴露了一个全局函数，在控制台 / 油猴脚本 / 其他页面里都能直接调：

        
const src = await window.luauDecompile(uint8array);   // → 源码字符串
const dia = await window.luauDetect(uint8array);   // → "luau" / "luaujit" / ...

        
字节码从哪来：执行器里
          writefile("x.luau", getscriptbytecode(目标脚本))
          → 用 http.read("x.luau") 读成 string → 转 Uint8Array。

        
可选参数：

        
await window.luauDecompile(bytes, {
  naming:   { mode: "heuristic" },        // "debug-like" | "simple" | "heuristic"
  generate: { mode: "permissive",         // "strict" | "permissive"
              luauVectorConstructor: { constructor: "vector", size: 3 } }
});

        
⚠ 本页没有 HTTP 接口（纯静态站，POST /decompile 不会通）。
